# MiniGPT-TinyStories

An autoregressive language model (~27M parameters) based on the GPT architecture, built from scratch using PyTorch and trained on the TinyStories dataset.

---

## Architecture Overview

- **Model Type**: Decoder-only Transformer
- **Parameter Count**: ~27 Million
- **Layers**: 8 transformer blocks
- **Attention Heads**: 8
- **Embedding Dimension**: 512
- **Context Length**: 256 tokens
- **Vocabulary**: 4,096 tokens (Byte-Pair Encoding via Hugging Face `tokenizers`)
- **Key Enhancements**:
  - Pre-LayerNorm architecture with residual connections
  - Flash Attention acceleration via `torch.nn.functional.scaled_dot_product_attention`
  - Weight tying between token embeddings and language model head
  - Scaled residual projection initialization
  - Mixed precision training (bfloat16 / float16)
  - AdamW optimizer with cosine learning rate schedule and linear warmup

## Setup & Installation

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/minigpt-tinystories.git
cd minigpt-tinystories
```

### 2. Create and activate a virtual environment
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Linux / macOS:
source venv/bin/activate
```

### 3. Install requirements
```bash
pip install -r requirements.txt
```

## Usage

### Training from Scratch
Run `train.py` with default hyperparameters:
```bash
python train.py --out_dir checkpoints --max_steps 10000
```

Key arguments:
- `--max_steps`: Total training iterations (default: 10000)
- `--batch_size`: Batch size per iteration (default: 64)
- `--lr`: Peak learning rate (default: 5e-4)
- `--warmup_steps`: Number of warmup steps (default: 300)
- `--resume`: Resume training from the latest checkpoint

### Generating Stories
To generate stories from a trained checkpoint:
```bash
python generate.py --checkpoint checkpoints/minigpt_best.pt --tokenizer_dir checkpoints/tokenizer --prompt "Once upon a time, there was a little girl named Lily."
```

For interactive mode:
```bash
python generate.py --interactive
```
